# Interface Ad Rock Console UI

O login e as páginas administrativas usam como referência visual `../relatorios-porvir/design/DESIGN.md` e `../relatorios-porvir/src/index.css`. Os arquivos do projeto de referência não foram alterados.

- Fundo claro com gradiente suave, superfícies brancas e bordas azul claras.
- Botões de ação laranja, texto escuro e foco visível.
- Logo Ad Rock do projeto de referência, copiado para `app/static/adrock-logo.png`.
- Login em duas colunas no desktop e uma coluna em telas menores; cabeçalho e navegação compartilhados nas páginas internas.
- O editor mantém a prévia PDF como área principal e expõe altura e máximo de linhas do campo para nomes longos.
