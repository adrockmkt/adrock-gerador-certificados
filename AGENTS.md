# Instruções para agentes

- Leia `README.md`, `docs/spec.md` e a etapa relevante de `docs/implementation-plan.md` antes de implementar.
- Use `AI_ENGINEERING_PLAYBOOK.md` em `../modelos_de_codigo/` como governança organizacional.
- Implemente uma etapa por vez e valide seus critérios antes de avançar.
- Não faça deploy nem altere a infraestrutura existente sem autorização específica.
- Não inclua PDFs, CSVs, certificados, banco de dados, credenciais ou dados pessoais no Git.
- Revise o diff e registre testes e riscos antes de declarar uma etapa concluída.
